# Install this README as your GitHub profile

GitHub displays a profile README when your account owns a **public** repository with exactly the same name as your login, and that repository contains a root README.md.

Your login is `MUHRIS-AJ`, so the special repository should be `MUHRIS-AJ/MUHRIS-AJ`.

Current connector tools can update existing repositories, but do not expose the create-repository action. The profile README has been prepared here without pretending that the special profile repository exists.

## One-time setup
1. Open https://github.com/new.
2. Set repository name to **MUHRIS-AJ** under owner MUHRIS-AJ.
3. Choose **Public** and create the repository with a README.
4. Copy the contents of docs/github-profile/README.md from the portfolio repository into the special repository's root README.md.
5. The banner is hosted from this portfolio repo at docs/github-profile/hero.svg after merge to main.

No external GitHub stat or trophy service is needed. The profile only lists actual projects and clearly identifies ResearchGuard as a prototype. All links target your own public code.
