# How A.J. Muhris Works with AI

I use AI to explore designs, analyze requirements, prototype ideas, and generate testing approaches. I evaluate its suggestions rather than assuming the output is accurate.

1. Define a real user and measurable problem.
2. Ask AI to challenge assumptions and propose alternatives.
3. Verify domain claims using official sources and live data.
4. Build tool contracts and MCP interfaces with limited permissions.
5. Implement incrementally; use Git branches and automated checks.
6. Ask AI to critique code, failure modes and test coverage.
7. Manually inspect results, run tests and evaluate edge cases.
8. Document status, limits, licensing and known risks.
9. Request review before merging changes to production.
10. Measure improvements in user outcomes, not just feature counts.

Suggested collaborator roles: researcher, architect, implementer, QA, security reviewer, technical writer.

The portfolio's visible code projects are the evidence of learning; it does not publish invented skill scores or artificial awards.
